# Bazar Frontend

React + TypeScript + Vite + Tailwind CSS v4.

## Архитектура

```
src/
├── app/                 # точка входа приложения
│   ├── App.tsx
│   ├── providers.tsx    # глобальные провайдеры
│   └── router.tsx       # маршруты
├── components/
│   ├── layout/          # каркас интерфейса (sidebar, chat area)
│   └── ui/              # дизайн-система (button, input, avatar, badge)
├── features/            # фичи по доменам
│   ├── auth/            # вход / регистрация (второй фронтендер)
│   ├── chats/           # список чатов, базары, точки
│   └── messages/        # сообщения, сокеты, поиск
├── hooks/
├── lib/                 # утилиты (cn, api-клиент позже)
├── stores/              # Zustand
├── styles/              # токены и глобальные стили
└── types/               # общие TypeScript-типы
```

## Дизайн-система

Тёмная тема по умолчанию. Палитра из мудборда, но **акценты используются точечно**:

| Токен | Цвет | Где |
|---|---|---|
| `bg` | `#2A1133` | фон приложения |
| `brand` | `#9F3054` | primary-кнопка, исходящие сообщения |
| `accent` | `#F4C430` | только бейдж непрочитанных |
| `success` | `#7FBC3B` | только онлайн-статус |
| остальное | нейтральные фиолетово-серые | карточки, текст, границы |

Токены: `src/styles/tokens.css`

## Запуск

```bash
npm install
npm run dev
```

## Зоны ответственности

- **Лера**: `components/ui`, `features/messages`, WebSocket, окно чата
- **Второй фронтендер**: `features/auth`, создание базаров/точек, участники
